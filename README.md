# NYSC TSI — Subdomain Registration Platform

A web platform built to handle subdomain registration and management. This was the first working version of the system, later refined and expanded into a more advanced platform.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Features
- Subdomain registration and management
- Responsive, mobile-first interface
- Built on the modern Next.js App Router architecture
